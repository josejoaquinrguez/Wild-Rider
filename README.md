Wild Rider

Aplicación Android para motoristas

Wild Rider es una aplicación móvil desarrollada como Trabajo de Fin de Grado del ciclo formativo de Desarrollo de Aplicaciones Multiplataforma (DAM).

El proyecto tiene como objetivo ofrecer a los motoristas una herramienta para registrarse y compartir ubicaciones y puntos de interés con otros usuarios.

Funcionalidades

- Registro de usuarios.
- Compartir ubicaciones con otros usuarios.
- Integración de Google Maps.
- Gestión de usuarios mediante Firebase.

Tecnologías utilizadas

- Kotlin: lenguaje de programación.
- Android Studio: entorno de desarrollo.
- Firebase: servicios de backend y gestión de usuarios.
- Google Maps API: integración de mapas y ubicaciones.

Descargar aplicación

Puedes descargar e instalar la versión APK desde el apartado de Releases de este repositorio.

Instalación y configuración

Para ejecutar el proyecto desde Android Studio necesitarás:

1. Descargar o clonar este repositorio.
2. Abrir el proyecto con Android Studio.
3. Configurar Firebase con tu propio proyecto.
4. Añadir una clave API propia de Google Maps.
5. Sincronizar Gradle y ejecutar la aplicación.
